🏨 Vic Modern Hotel – Enterprise Network Design & Implementation

📌 Project Overview

This project focuses on designing and implementing a three-floor enterprise network infrastructure for Vic Modern Hotel using Cisco Packet Tracer.

The network is designed to provide secure, reliable, and efficient communication between different departments across all three floors.

🎯 Project Objectives

* Design a structured enterprise network.
* Implement VLAN segmentation for different departments.
* Establish communication between multiple routers.
* Configure dynamic routing and IP address allocation.
* Improve network security and accessibility.
* Test connectivity between different network segments.

🛠️ Technologies & Concepts Used

* Cisco Packet Tracer
* VLAN Configuration
* Inter-VLAN Routing
* OSPF Dynamic Routing
* DHCP Configuration
* SSH Remote Access
* Port Security
* Sticky MAC Address
* Wireless Networking
* Serial DCE Connections

🏢 Network Structure

The hotel network consists of three floors connected through routers and switches.

🖥️ 1st Floor

* Reception
* Store
* Logistics

🖥️ 2nd Floor

* Finance
* HR
* Sales & Marketing

🖥️ 3rd Floor

* Administration
* IT Department

⚙️ Key Implementations

1. VLAN Segmentation

* Separate VLANs for different departments.
* Improved network organization and traffic management.

2. OSPF Dynamic Routing

* Dynamic route exchange between routers.
* Communication between different network segments.

3. DHCP Configuration

* Automatic IP address allocation to network devices.

4. SSH Remote Access

* Secure remote management of network devices.

5. Port Security

* Sticky MAC address configuration.
* Port security to restrict unauthorized device connections.

6. Wireless Connectivity

* Wireless network access for supported devices.

7. Network Connectivity Testing

* Ping testing between different network segments.
* Verification of network communication.
